Birth Family Tool

Test version for Search Angels volunteers. Windows only for now.

This tool helps you work an adoptee's AncestryDNA matches the way an experienced searcher would. You collect the matches, it sorts them into the two parents' sides and into family groups, points at the most recent shared ancestors, and then helps you step down one generation at a time toward the birth parents.

It's a first version. Please use it on a case you already know the answer to, so you can tell us where it's right and where it's wrong.

Why you press the keys yourself

Ancestry doesn't allow bots, AI agents or other automated tools to collect data from its website. Its terms, updated in May 2026, are clear about that, and Ancestry has shut down tools that did it in the past.

So this tool never touches Ancestry. You do the browsing. On each page you press Ctrl+A (select everything) and then Ctrl+C (copy), the same as you might do by hand to save a page. The tool only reads what's on your computer's clipboard and files it for you.

Everything stays on your computer. Nothing about a case is uploaded or sent anywhere. The only time the tool goes online is to check whether a newer version of itself is available.

What you need

  • A Windows computer.
  • Access to the adoptee's AncestryDNA matches (see "Getting access" below).
  • About 15 to 20 minutes for a first run.

Step 1: One-time setup

  1. Install Python. Open the Microsoft Store, search for Python, and install the newest one published by the Python Software Foundation. It's free. You don't need to open it afterward.
  2. Unzip this folder somewhere easy to find, such as your Documents folder. Don't run the files from inside the zip.

The first time you double-click one of the two launcher files, Windows may ask whether you're sure you want to run it. Choose "More info" and then "Run anyway".

Getting access to the adoptee's results

The adoptee stays the owner of their DNA results and invites you in. Two separate invitations are involved.

DNA results: ask for the Collaborator role

The adoptee goes to Account Settings, then DNA, picks their test, opens "DNA test sharing" and invites you by email.

RoleWhat it allows, according to Ancestry's help pages
ViewerSee the results and matches. No changes.
CollaboratorEverything a viewer can do, plus add notes, group matches and link the test to a tree. This is the one to ask for.
ManagerAlso invite others, download or delete the DNA data, and send messages as the owner. More than a searcher needs.

Family tree: ask for the Editor role

If the working tree lives in the adoptee's account, they invite you to it from the tree's settings.

RoleWhat it allows
GuestView and comment. Can't see living people.
ContributorAdd comments, photos and stories. Can't change the tree or see living people.
EditorAdd, change and remove people, and see living people. This is the one to ask for.

Ancestry changes these screens from time to time. If what you see doesn't match, tell us what the choices are now.

Step 2: Capture a case

Double-click 1 Capture a case. Type a short name for the case and press Enter. A small window opens and stays on top of your browser.

What the window shows

  • A bold heading with the step you're on, and plain instructions under it.
  • A big green number that counts up as the tool takes in what you copied. If it's climbing, it's working.
  • A coloured bar that tells you what just happened:
WAITINGReady for you to copy a page.
PROCESSINGReading what you copied. Takes a moment.
RECEIVEDGot it. Go on to the next page.
NOT RECOGNISEDThat wasn't the page it asked for. Nothing is lost. Read the message, open the right page and copy again.

The three steps it walks you through

  1. Match list. On Ancestry open DNA, then Matches. Click Filter, then Shared DNA, then Custom centimorgan range. Type 90 in Min, leave Max empty, and apply. Set 50 per page at the bottom. Press Ctrl+A, then Ctrl+C. Go to the next page and repeat until the window says the list is done.
  2. Public trees. Back on the match list, click Filter, then Trees, then Public linked trees, and apply. The window names one person at a time. Click that name, press Ctrl+A, then Ctrl+C, then your browser's Back button. You can do them in any order.
  3. Shared matches. Set the Trees filter back to All. For each person the window names, click the name, click the "Shared Matches" tab on their page, then press Ctrl+A, Ctrl+C.

The filters are only on the main match list, not on a person's page. If you don't see Filter, press Back.

Two buttons help you along: Skip this person if you can't open someone, and Finish this step when you've done enough. You don't have to do every name. You can close the window at any time and pick the case up later by running the launcher again with the same case name.

Step 3: Read the report

When you close the window, a report opens in Notepad. It's organised as two family trees, one for each parent's side, because that's how the search works.

For each side it shows:

  • The closest match, marked "start here", and what that amount of DNA usually means.
  • Family groups (clusters) of matches who also match each other.
  • Surnames that turn up in more than one of those matches' trees.
  • People who appear in two or more trees, most recently born first. The top one is your most recent common ancestor to work from.
  • Which family groups should join by marriage on the way down to that parent.

The report ends with an endogamy check. If it warns you, the matches are probably more distant than their numbers suggest, and you shouldn't trust the tool's relationship guesses on that case.

Step 4: Work the case

Double-click 2 Work the case, type the case name, and pick from the menu.

ChoiceWhat it does
1. Save birth year and placeDo this first. It lets the tool say which generation someone belongs to and whether they're the right age to be a birth parent.
2. Show the reportOpens the report again, updated.
3. Make the starting tree fileBuilds the blank canvas: the adoptee, two unknown parents, and the closest match on each side hung from "Unknown" placeholders. Upload it to Ancestry as a new private tree and link the adoptee's DNA to the adoptee in it.
4. Walk down the generationsYou type a shared ancestor couple, then each of their children, who each child married, and the child's birth year. The tool checks whether each spouse's family also shows up in the matches and tells you which child to follow. Repeat until it reaches the birth parents.
5. Surname checkType a surname and see which matches carry it or have it in their tree, and on which parent's side.
6. cM checkType a cM amount and a relationship a tree claims, such as 497 and 1C1R. The tool says whether that's believable. Good for catching mistakes in public trees.

Public trees hide living people as "Private", so they usually run out at the grandparents. For the generations after that you'll still need obituaries and records, as you do today. The walk reminds you of that at each step.

What this version can't do yet

  • It's been tried on one real case. That case came out right on three of four family lines. Expect rough edges on yours.
  • Spelling has to match. Smith and Smyth count as two different surnames.
  • It only reads the small tree preview on each match's page, not the full tree.
  • It doesn't know ages unless you type birth years into the walk.
  • The starting tree file hasn't been uploaded to Ancestry yet by anyone. If Ancestry rejects it or the Unknown people look wrong, tell us.
  • It can't correct for endogamy. It only warns.
  • Nothing here is proof. It narrows where to look. Records confirm.

Privacy

  • Each case is saved in the cases folder next to these files. It holds real names of the adoptee's matches.
  • Keep that folder on your own computer. Don't email it or put it in a shared drive.
  • When a case is finished, delete its folder.
  • Never type a Social Security number into the tool. It only needs the state.

What we'd like to hear back

  • Did the window ever turn red on a page you were sure was right? Which step?
  • Were any instructions unclear, or did Ancestry's screen not match them?
  • Did the report point at the right families for a case you've already solved?
  • Did the walk follow the right child at each generation?
  • What did you have to do by hand that you wish it did for you?

Send suggestions and bug reports to support@searchangels.org with "Birth Family Tool" in the subject line. Say which step you were on and what the window said.

If something goes wrong, the pastes folder inside the case holds a copy of every page you copied. That's what we need to fix it, but it contains real names, so check with the case owner before sharing it.

Updates

Each time you start the tool it checks for a newer version. If there is one, it asks before changing anything. Press Enter to update, then close the window and start the tool again. Your cases aren't touched by an update, and the version you had is kept next to the new one as birthfamily.py.previous.

If the tool can't reach the update site, it says nothing and carries on with the version you have.
